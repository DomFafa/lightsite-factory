# 401k Calculator Golden Sample

This folder stores lessons from the 401k calculator golden sample.

It is not a fixed template. Future sites must not copy this sample directly. Use it to preserve quality standards, UX rules, and QA learnings that can improve future generated static tool sites.

Rules are organized into:

- Global rules for all generated tool sites.
- Calculator-family rules for calculator-style pages.
- 401k-specific rules for this golden sample.
