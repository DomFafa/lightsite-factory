# Random Date Generator v0 Learning Notes

## What Happened

- The generated UI was usable and the tool behavior worked.
- The result still felt like a generic generated utility rather than a deliberate design-first product.

## Issues

- H1 and hero chips were too large relative to the actual tool.
- Section tokens did not inherit compact sizing strongly enough.
- Decorative illustration felt AI-template-like rather than refined.
- The code model was still doing too much free UI design after planning.

## Lesson

Random Date Generator is a good Phase 2 simple/medium tool, but it needs the design-target stage before code generation so the code model implements a clear visual target rather than inventing the UI from text alone.
